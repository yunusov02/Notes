
**Machine Learning (ML)** - where we build programs that learn patterns from data instead of being explicitly programmed with rules

Traditional Programming
```bash
Rules + Data --> Program --> Output
```

Machine Learning
```bash
Data + Correct Answers ---> Linear Algorithm - Model ---> Predictions
```


Instead of writing hundreds of if statements we let the computer discover the rules

**Learning Means**
Finding a mathematical function that maps inputs to outputs


**Features (X)**
```bash
Area
Bedrooms
Bathrooms
```

The last column is called

**Target (y)**
```bash
price
```


**What is a Model**
A model is the thing that learns patterns

**Training** teaching the model
```bash
100,000 house prices

↓

Training

↓

Model learns relationship
```

**Prediction (Inference)**
After training we use the model
```bash
New house

↓

Model

↓

Predicted price
```
