
### Vectors

A vector is simply an ordered collection of numbers
```bash
[2, 3, 4, 5, 2]
```

Imagine we are describing a person
instead of writing
```
age = 24
height = 190
weight = 90
```

you can write
```bash
x = [24, 190, 90]
```

### Vector operations
```
A = [1, 2, 3]
B = [4, 5, 6]

```
