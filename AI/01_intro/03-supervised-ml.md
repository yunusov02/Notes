**Supervised Machine Learning**  is the type of ML where the model learns from labeled data

A **label** is simply correct answers

- Inputs (features X) and correct outputs(labels y) are both available during training
- the model learns relationship between inputs and outputs
- after training it can predict outputs for new unseen inputs

The two main categories
- Regression -> predict a numeric values (house price)
- Classification -> predict a category (spam vs not spam)
	- Multiclass (cat dog car)
	- Binary (spam not spam)

**g(X) = y**

- `g()` -  model
- `X` -   features
- `y` -  target variable
