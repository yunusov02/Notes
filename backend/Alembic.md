
Alembic is the migration tool for SQLAlchemy

Think of it is a git but for database schema



first install alembic

```bash
uv add alembic
```

and initialize alembic
```bash
alembic init alembic
```

structure
```bash
alembic/
├── versions/
├── env.py
├── script.py.mako
└── README

alembic.ini
```
